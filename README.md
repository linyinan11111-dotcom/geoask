# geoask

**用一句话说清想去哪，查询多个地点，再把它们连成一条出行路线。**

geoask 是一款自然语言地点查询与行程规划工具。通过 DeepSeek 理解你的需求，结合高德地图查找真实地点，并规划步行、骑行或驾车路线。

> “我想先喝咖啡，再去健身，最后找个餐厅吃饭。”
>
> 理解需求 → 按顺序查找咖啡店、健身场所和餐厅 → 选择地点 → 在地图上规划完整路线。

## 理解日常语言

不必把需求拆成关键词，也不必逐个填写目的地。程序可以从一句话中提取**地点需求、具体名称、先后顺序和出行方式**。

| 你怎么说 | 程序如何理解 |
| --- | --- |
| “我想喝咖啡” | 查找附近的咖啡店 |
| “我想去鸟巢看演唱会” | 保留“鸟巢”这个目的地和“看演唱会”这项活动，搜索对应地点供确认 |
| “先去鸟巢，再找附近的咖啡店” | 区分具体地标与地点类别，按顺序查询两站 |
| “骑车先喝咖啡，再去健身” | 提取两个站点，并采用骑行方式规划路线 |

支持口语化表达、地标俗称与别名识别。具体地点以地图搜索结果和用户确认为准；“安静”“适合约会”等描述词可以被提取和展示，目前不作为地点筛选条件。

## 多点位查询与路径规划

**一次最多解析 6 个站点，完成从需求到路线的连续规划。**

1. **按顺序查询多个地点。** 附近类别查询的第一站围绕起点搜索，后续站围绕前一站选定地点搜索。
2. **每一站都能自己选。** 查看候选并切换门店或地标；更换中途站点后，程序重新查询后续站点，支持重新规划路线。
3. **沿真实道路规划。** 支持步行、骑行、驾车，在地图上展示完整路线，并提供分段距离、预计用时和转向指引。
4. **查看和保存行程。** 地图展示起点及各站点，支持拖动、缩放和行程 CSV 导出；还可选择驾车到最后一站附近的停车场。

例如：

```text
起点 → 咖啡店 → 健身场所 → 餐厅
```

路线保留你指定的访问顺序；附近类别查询默认逐站选择最近候选，不保证全局最短行程。地点查询与道路路线来自高德地图，语言模型负责理解需求。

## 开始使用

### Windows 桌面版

在 [GitHub Releases](https://github.com/linyinan11111-dotcom/geoask/releases/latest) 下载 Windows x64 压缩包，完整解压后打开 `geoask.exe`，无需安装 Python。

### 从源码运行

需要 Python 3.11–3.13，在项目目录执行：

```powershell
python -m pip install -r requirements.txt -e .
python geoask_gui.py
```

Windows 也可以在安装依赖后双击 `启动界面.cmd`。Linux 如缺少 Tkinter，需安装系统的 `python3-tk` 包。

### 第一次查询

1. 打开“接口设置”，填写 **DeepSeek API Key** 和 **高德 Web 服务 Key**，点击“应用所有设置”。可勾选保存到本机，下次自动读取。
2. 设置起点：获取设备位置、手动输入经纬度，或在地图上右键选点。设备定位目前支持 Windows。
3. 输入一句需求，例如“我想先喝咖啡，然后去健身”，开始查询。
4. 查看并确认各站地点，选择出行方式，点击“规划路线”。

自然语言解析、地点查询和道路规划需要联网及有效密钥。默认使用高德在线查询；找不到地点或请求失败时会明确提示。演唱会等活动词用于理解出行目的，不提供演出日程或票务查询。
