# 剩余 P3 修复记录（2026-10-23）

本批接续 [第二轮修复](review-round2-fixes.md)，保留原审查报告及仓库示例数据。

## 已实现

- 查询期间真正禁用 preview/auto_route 控件，真实 Tk 测试验证点击不会改变已提交请求对应的值，空闲后恢复。
- 日志初始化加线程锁；事件错误日志不再访问 `event[0]`，畸形事件也能恢复并继续处理后续事件。
- 文件输出支持按需创建父目录，清理失败不掩盖原异常，替换保留 POSIX 权限位。新配置用系统提供的原子不覆盖重命名，不创建零字节占位、不依赖硬链接；并发写仅一人成功，进程中断不会暴露空配置。Windows 用原生 rename，Linux/macOS 使用系统 no-replace rename；不支持时安全失败并提示换目录。
- 停车 SQL 在 LIMIT 前计算去重后总数，提示截断及如何查看更多；未命名候选显示坐标。后台与真实 Tk 事件接线均测试。
- 数据准备共用固定归档 SHA256、布局检查、原子下载与解压、缓存大小/CRC 验证；同大小的损坏缓存也重新提取。数据导出回读和国家体育场唯一性检查都在替换前；清单发布失败回滚旧数据。
- 新增 `verify_data.py`，在临时目录真实重建样例和地名目录，核对统计/别名/清单哈希；仓库 data 文件保持原哈希。
- Windows 启动器检查 Python 3.11–3.13、Tk、pythonw 和即时启动失败，依赖/版本不满足返回非零并显示安装提示。启动器异步运行，不保证稍后发生的应用异常通过批处理退出码返回；traceback 写滚动日志。
- 发布元数据加入 README、MIT 许可和 Python/GIS 分类；`geoask_resources.__version__` 为单一版本源，构建版本与默认 HTTP User-Agent 共用。未提供远程仓库 URL，因此没有编造项目链接。
- 限制 modifiers 长度/数量，拒绝变换后 NULL 坐标；E5 使用 query/passage 前缀，缓存键包含前缀。完整 finish_reason 与显式 travel_mode 规则已有实现，新增回归固定契约。
- 地名检查脚本导入不再访问数据库；演示渲染可指定中文字体；行程验证报告新增时间/代码哈希，并重新生成。sdist 包含准备/验证脚本与启动器。

## 保留的限制

- 未配置 Git remote，未触发或声称远程 CI 全绿；修改仍留在工作区。
- zipapp/PEX 中未解压资源不在支持范围，继续支持普通 wheel/源码安装。
- 数据与清单是两个独立文件，无法保证断电时同时提交；清单哈希可用于检查不一致，脚本可重新生成。回滚测试针对可捕获发布错误，不能把它等同于断电事务。
- 进程被强杀可能留下临时文件，但不会留下新配置的空目标；多进程共享同一滚动日志的轮转协调仍未实现。
- 启动器的 Windows 路径分支及 POSIX 权限分支没有在所有系统实机验证；真实设备 GPS 权限/信号仍取决于系统。
