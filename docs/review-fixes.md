## 中优先级及工程修复

- 损坏/空/zip/错误行数/非有限/零向量缓存重建；查询发现缓存维度不符时重建。
- 字段映射忽略大小写；空白、null 和 GDAL 返回的 JSON 文本数组别名均清洗，避免无名称数据通过校验。
- “不明确 / unknown / 未知”作为解析失败处理，不进入类别映射。
- 瓦片缓存读取失败可重取；写缓存失败仍显示有效下载；坏图不再中止轮询。启动及底图切换时清理过期或超出 128 MiB 的瓦片。
- 地区配置保存不依赖硬链接；禁止覆盖已有配置，保存错误转为可理解提示。配置、CSV、瓦片共用临时写入与替换工具。
- 设置对话框两个应用按钮统一校验并保存全部页面，保留另一页未保存的会话密钥。
- 新查询清理旧站点控件；失败时禁用无结果的选择器。请求携带代际 ID，忽略过期事件。
- CLI 输入无效、语义失败和空结果返回非零；名称查询前也验证有限半径。
- 新增滚动日志、无头 GUI/地图测试、定位 subprocess 测试、安装冒烟脚本；快照断言改读 manifest 或选择有效候选。
