## 高优先级与中优先级

| 报告问题 | 最终行为与回归证据 |
| --- | --- |
| 错误图层导致原生崩溃 | 先用 `ST_Read_Meta` 枚举图层，精确匹配优先，其次唯一的大小写不敏感匹配。不存在时中文报错并列出可用图层，未经验证的名称不传入 `ST_Read`。主数据、补充目录和地区导入均覆盖；6 个独立子进程测试检查退出码，不能用 Python 异常捕获代替原生崩溃检测。 |
| 停车守卫误杀合法需求 | 只识别解析后的目的类别，不扫描原始整句或 modifiers。咖啡/餐厅携带停车修饰词仍查对应类别；修饰条件明确显示未应用。单站、多站和 CLI 使用同一匹配路径。 |
| 自定义停车类别不可达 | 主数据含配置的汽车停车类别时，直接走受控类别参数查询，可查询多个类别，跳过嵌入模型。没有类别时提示切换数据；GUI 可另选目的地后启用停车导航。不把停车场映射为公园。 |
| 相对配置静默迁移缓存 | 先规范化配置绝对路径，只有普通安装的内置配置使用用户缓存目录。同一源码配置相对/绝对路径缓存相同。 |
| 混合数组/标量别名 | 对每个数组元素再次拆分 `;；|`，展开、去空、去重；回归断言精确别名 rank 0。 |
| 空别名错误选择未命名停车场 | 配置拒绝空 key/target；查询层另有防御，绕过模型校验也不能用空 key 匹配。已核实别名目标不存在时回退原始名称；目标存在时仍优先正式名称，避免鸟巢观景点替代国家体育场。 |
| 导入暴露 DuckDB 英文错误 | 元数据、字段、CRS/几何读取和补充目录错误转为中文操作提示，原异常写日志。无效 CRS、文本几何列和损坏文件均有回归，失败不落盘。 |
| GUI 验证依赖被忽略的缓存目录 | 测试导入文件放系统临时目录，mainloop 在 finally 中关闭窗口、恢复解析器和清理临时文件；不再要求预先存在 `.cache/`。首次模型下载和真实网络服务仍是该脚本的前提。 |
| Linux CI 缺 Tk/显示环境 | 显式安装 `python3-tk`、Xvfb，检查 Tk 导入；Linux 测试和安装冒烟用 `xvfb-run`。缺失显示环境在 CI 中失败，job 超时 20 分钟。远程矩阵尚未执行。 |
