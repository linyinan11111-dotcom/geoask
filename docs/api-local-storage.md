# API 设置本地保存：使用说明与验证记录

日期：2026-10-26。

## 1. 用户如何使用

1. 双击仓库根目录的 `启动界面.cmd`。
2. 打开“接口设置”，填写接口地址、模型名称和 API Key。DeepSeek 使用兼容地址及 `json_object` 返回格式。
3. 保持“保存接口和密钥到本机，下次自动读取”勾选，点击任意一页的“应用所有设置”。
4. 下次启动默认界面，自动恢复模型、接口地址、地图/路径接口设置和密钥，无需重新填写。

两个设置页共用一次应用动作，因此在模型页填写密钥后切换至地图页应用，也不会丢弃密钥。

选择“清除本地保存的接口和密钥”会立即删除保存文件并清空当前会话密钥。取消保存勾选后应用，也会删除旧文件，输入内容仅供本次运行使用。这两种操作都不修改系统环境变量。

## 2. 保存位置与保护方式

| 系统 | 文件位置 | 保护方式 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\geoask\connection.dat` | 当前 Windows 用户的 DPAPI 加密 |
| Linux | `$XDG_CONFIG_HOME/geoask/connection.dat`，默认 `~/.config/geoask/connection.dat` | JSON 明文，文件权限 `0600` |
| macOS | `~/Library/Application Support/geoask/connection.dat` | JSON 明文，文件权限 `0600` |

Windows 缺少 `LOCALAPPDATA` 时使用 `APPDATA` 或当前用户目录。新建的 POSIX 配置目录使用 `0700`，不会修改已存在共享父目录的权限。

文件包含版本号、LLM 配置、地图配置、道路配置及密钥；并非写入仓库 `config.yaml`。Windows 加密针对整个 JSON 负载，密钥没有作为明文写入该文件。不使用全机器解密标志，不需要额外安装加密包。相同 Windows 用户的进程仍可解密；不能将其理解为防御已经获得当前账户权限的恶意程序。

保存使用同目录临时文件和原子替换。替换失败时保留旧文件，界面显示中文错误并保留输入。文件损坏、超过大小限制或无法解密时提示清除/重新保存，不输出密钥或文件内容。

当前保存一套全局连接配置；没有多账户/多服务密钥库，也没有把 Windows 加密文件复制到另一台电脑继续使用的保证。

## 3. 配置与密钥优先级

GUI 密钥选择顺序：**本次明确应用的输入 → 当前 LLM 指定的环境变量 → 匹配的本地密钥**。

启动恢复的密钥虽然在输入框显示为掩码，但不会被当成本次明确输入，从而允许环境变量覆盖。修改表单并应用属于本次明确选择。

默认 GUI 启动会恢复整套保存连接；主动切换自定义 YAML 时保留该 YAML 的服务参数，仅在接口身份匹配时复用保存密钥。接口身份包含协议、主机、端口、路径、URL 查询参数和密钥环境变量名；更换服务不会自动发送旧服务密钥。模型名称可以更换而继续使用同一服务的密钥。

CLI 保留 `--config` 对地址、模型等参数的控制权，密钥按“环境变量 → 匹配的本地密钥”读取。GUI 保存了其他地址后，CLI 必须使用具有相同服务身份的配置，才会读取对应密钥。CLI 不会悄悄将用户 YAML 的地址替换为 GUI 保存的地址。

没有配置密钥的本地兼容服务仍沿用项目原有要求，可填写该服务接受的占位密钥；这次改动没有新增服务认证探测。

| `tests/test_credentials.py` | 存储、加密、损坏、替换失败、服务边界、跨进程、解析器测试 |

## 5. 验证范围

本机 Windows / Python 3.13 完整 pytest：**211 项通过**，启用了真实本地嵌入模型和真实 Tk 接线测试。测试密钥均为固定假值，不调用付费 DeepSeek API。所有自动测试隔离真实凭据文件。

已验证：Windows 加密文件不包含测试密钥明文；新的 Python 子进程能在同一用户下解密恢复；接口地址或环境变量名不同不会复用密钥；环境变量可以覆盖保存密钥；解析意图和行程均能读取保存密钥；保存失败保留旧文件；取消保存及清除操作生效。

真实桌面验证已通过，包括地图/路线网络、地区导入、跨页应用、设置窗口布局，以及本地保存 → 恢复 → 清除。验证脚本使用临时假密钥，不读取或覆盖用户真实凭据。实际桌面与发行包的最终检查结果见 [可靠性验证清单](reliability-verification.json) 和 [GUI 验证记录](gui-verification.json)。截图与真实网络验证独立于 pytest；应分别查看对应时间和状态，不用旧记录代替新检查结果。

## 6. 升级与排错

旧版 editable 安装需要在项目虚拟环境中重新执行：

```powershell
python -m pip install -e .
```

仅更新源文件不会自动把新模块注册进旧安装元数据。本次已在当前 `.venv` 执行刷新。

- 重启后没有恢复：检查是否勾选保存并点击应用、是否使用同一系统用户、是否主动切换了其他服务配置。
- 本地设置无法读取：在接口设置中清除后重新保存；不要把加密文件当作可移植明文配置编辑。
- 保存失败：检查用户配置目录权限或占用，界面会保留尚未应用的输入供重试。
- 清除后仍可查询：检查相应环境变量是否存在；删除文件不会修改环境变量。
- 设置了本地接口但 CLI 没使用：检查 CLI YAML 的 `llm` 地址及 `api_key_env`，CLI 不覆盖这些参数。
