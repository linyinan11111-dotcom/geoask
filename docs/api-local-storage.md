# API 设置本地保存：使用说明与验证记录

日期：2026-10-26。

## 1. 用户如何使用

1. 双击仓库根目录的 `启动界面.cmd`，或运行 `python geoask_web.py`。
2. 打开“接口设置”，填写接口地址、模型名称、DeepSeek API Key，以及高德 Web 服务 Key 和安全 Code。DeepSeek 使用兼容地址及 `json_object` 返回格式。
3. 勾选保存到本机，点击“保存设置”。
4. 下次启动默认界面，自动恢复模型、接口地址、DeepSeek 密钥和高德凭据。底图和高德模式以当前 `config.yaml` 为准。

选择“清除本地保存的接口和密钥”会立即删除保存文件并清空当前会话密钥。取消保存勾选后应用，也会删除旧文件，输入内容仅供本次运行使用。这两种操作都不修改系统环境变量。

## 2. 保存位置与保护方式

| 系统 | 文件位置 | 保护方式 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\geoask\connection.dat` | 当前 Windows 用户的 DPAPI 加密 |
| Linux | `$XDG_CONFIG_HOME/geoask/connection.dat`，默认 `~/.config/geoask/connection.dat` | JSON 明文，文件权限 `0600` |
| macOS | `~/Library/Application Support/geoask/connection.dat` | JSON 明文，文件权限 `0600` |

Windows 缺少 `LOCALAPPDATA` 时使用 `APPDATA` 或当前用户目录。新建的 POSIX 配置目录使用 `0700`，不会修改已存在共享父目录的权限。

文件包含版本号、LLM 配置、地图配置、道路配置、高德凭据及 DeepSeek 密钥；地图/道路副本仅作兼容记录，启动时以当前 `config.yaml` 为准。并非写入仓库 `config.yaml`。Windows 加密针对整个 JSON 负载，密钥没有作为明文写入该文件。不使用全机器解密标志，不需要额外安装加密包。相同 Windows 用户的进程仍可解密；不能将其理解为防御已经获得当前账户权限的恶意程序。

保存使用同目录临时文件和原子替换。替换失败时保留旧文件，界面显示中文错误并保留输入。文件损坏、超过大小限制或无法解密时提示清除/重新保存，不输出密钥或文件内容。

当前保存一套全局连接配置；没有多账户/多服务密钥库，也没有把 Windows 加密文件复制到另一台电脑继续使用的保证。

## 3. 配置与密钥优先级

桌面界面的密钥选择顺序：DeepSeek 为**本次明确保存的输入 → 当前 LLM 指定的环境变量 → 匹配的本地密钥**；高德为**环境变量 AMAP_WEB_KEY / AMAP_SECURITY_CODE → 本地保存的高德凭据**。缺少高德 Key 时会直接提示。

启动恢复的密钥虽然在输入框显示为掩码，但不会被当成本次明确输入，从而允许环境变量覆盖。修改表单并应用属于本次明确选择。

默认桌面启动会恢复保存的模型接口、DeepSeek 密钥和高德凭据；地图和高德参数以当前 `config.yaml` 为准。主动切换自定义 YAML 时保留该 YAML 的服务参数，仅在接口身份匹配时复用保存密钥。接口身份包含协议、主机、端口、路径、URL 查询参数和密钥环境变量名；更换服务不会自动发送旧服务密钥。模型名称可以更换而继续使用同一服务的密钥。

CLI 保留 `--config` 对地址、模型等参数的控制权，密钥按“环境变量 → 匹配的本地密钥”读取。界面保存了其他地址后，CLI 必须使用具有相同服务身份的配置，才会读取对应密钥。CLI 不会悄悄把用户 YAML 的地址替换成界面保存的地址。

没有配置密钥的本地兼容服务仍沿用项目原有要求，可填写该服务接受的占位密钥；这次改动没有新增服务认证探测。

## 4. 代码变更入口

| 文件 | 作用 |
| --- | --- |
| `geoask_credentials.py` | 用户目录定位、DPAPI、负载校验、原子保存、读取、清除、服务身份匹配 |
| `geoask.py` | `resolve_api_key` 为单意图/行程解析提供统一密钥来源 |
| `geoask_web.py` | 接口设置的保存、清除、启动恢复和请求密钥优先级 |
| `pyproject.toml` | 将凭据模块加入正常安装 |
| `tests/conftest.py` | 测试期间把凭据文件重定向到临时目录 |
| `tests/test_credentials.py` | 存储、加密、损坏、替换失败、服务边界、跨进程、解析器测试 |
| `tests/test_web.py` | 本机接口上的保存、切换服务、隐藏密钥和清除 |
| `scripts/verify_wheel.py` | 安装后的模块、网页资源、入口和本机 HTTP 检查 |

模块位置见 [项目代码结构与技术架构详解](项目代码结构与技术架构详解.md)。保存格式和优先级以本文为准。

## 5. 验证范围

自动测试使用固定假密钥，不调用付费 DeepSeek 或高德接口，并把凭据文件重定向到临时目录。覆盖范围包括：Windows 加密文件不包含测试密钥明文；同一用户的新进程可以解密；接口地址或环境变量名不同不会复用密钥；环境变量可以覆盖保存密钥；意图和行程解析都能读取保存密钥；保存失败保留旧文件；取消保存及清除操作生效。桌面设置请求由 `tests/test_web.py` 覆盖。

macOS 未实测；硬件定位与付费语言模型不在自动测试范围内。

## 6. 升级与排错

旧版 editable 安装需要在项目虚拟环境中重新执行：

```powershell
python -m pip install -e .
```

仅更新源文件不会自动把新模块注册进旧安装元数据。本次已在当前 `.venv` 执行刷新。

- 重启后没有恢复：检查是否勾选保存并点击应用、是否使用同一系统用户、是否主动切换了其他服务配置。
- 本地设置无法读取：在接口设置中清除后重新保存；不要把加密文件当作可移植明文配置编辑。
- 保存失败：检查用户配置目录权限或占用，界面会保留尚未应用的输入供重试。
- 清除后仍可查询：检查相应环境变量是否存在；删除文件不会修改环境变量。
- 设置了本地接口但 CLI 没使用：检查 CLI YAML 的 `llm` 地址及 `api_key_env`，CLI 不覆盖这些参数。
